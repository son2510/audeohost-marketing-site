# Audeohost Marketing Site

Product-supportive marketing site for Audeohost — venue engagement platform (live TV audio to a
guest's own phone, plus sport and non-sport event discovery, over one Portal).

Single self-contained `index.html` (no build step, no dependencies) — inline CSS, inline SVG/PNG
assets, light/dark theme support. Deployed via GitHub Pages from the `main` branch root.

Companion materials (sales deck, market-position review) live outside this repo.
